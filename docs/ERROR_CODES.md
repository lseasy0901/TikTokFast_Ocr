# 错误码注册表(docs 即源;新增码先登记此表再使用)

格式:`<阶段域>-<编号>`。阶段域=卡在哪个阶段;编号段:1xx 前置缺失,
2xx 网络/外部,3xx 内部错误,9xx 等待超时/卡死。
状态落盘:`%LOCALAPPDATA%\LiveLens\logs\state.json`(进入关键阶段即写,
崩溃/卡死后即为"卡点"证据);取流失败另见 `logs/stream-diag.log`。

## NET — 连接与解析
| 码 | 含义 | 用户建议 |
|---|---|---|
| NET-301 | 未输入直播间地址 | 粘贴直播间地址后重试 |
| NET-302 | 页面获取超时 | 检查网络后重试(软件已自动重试一次) |
| NET-303 | 页面获取非 200(疑似风控) | 稍后重试;持续出现请反馈 |
| NET-304 | 页面在播但未命中裸流判据 | 请反馈(附错误码,可能页面结构变化) |
| NET-310 | 所有候选流均不可用 | 查看 stream-diag.log;确认浏览器能否打开该房间 |
| NET-320 | 无法从粘贴内容识别直播间链接 | 用抖音 App 分享按钮的「复制链接」后重试(支持短链/文案/纯房间号) |

## PLY — 播放
| 码 | 含义 | 用户建议 |
|---|---|---|
| PLY-401 | FFmpeg 7 运行时缺失/被隔离 | 重新安装,或将 ffmpeg.exe 放回 runtime\ffmpeg7 |
| PLY-402 | 播放管道启动失败 | 重试;持续出现请反馈 |
| PLY-903 | 等待首帧超时(断流/直播结束) | 重连直播间 |

## LIC — 授权 / AJ — 自动加入 / QR — 二维码
授权失败详见激活弹窗文案(服务端返回 invalid_key/already_redeemed/rate_limited);
AJ-3xx 自动加入失败 toast 均带原因(未校准/窗口未找到/前台切换失败/权限不足)。
