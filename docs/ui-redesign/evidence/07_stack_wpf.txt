### Result 1
- **Category:** Performance
- **Guideline:** Use DependencyProperty for custom-control binding targets
- **Description:** Binding target properties on custom controls must be DependencyProperties (sources can be plain CLR properties with INPC)
- **Do:** Define DependencyProperty for properties bound TO on a custom control
- **Don't:** Plain CLR properties as binding targets on custom controls
- **Code Good:** public static readonly DependencyProperty NameProperty = ...
- **Code Bad:** public string Name { get; set; } as binding target on custom control
- **Severity:** Medium
- **Docs URL:** https://learn.microsoft.com/en-us/dotnet/desktop/wpf/properties/dependency-properties-overview
- **Applies To:** wpf current
- **Status:** active
- **Verified At:** 2026-08-13
