# pages/preview-watermark.md — 直播预览与水印覆盖层

> 本文件**覆盖** `MASTER.md` 中冲突的部分；未提及处遵循 MASTER。
> **完整运动算法、实现方案与测试矩阵见 `docs/ui-redesign/WATERMARK_SPEC.md`。**

---

## 1. 层次结构

```
┌─ 预览容器 (L1 内容面板 #171B24) ────────────────────────────┐
│                                                            │
│   ┌─ 视频显示层 (现有控件，不改动绘制逻辑) ─────────────┐    │
│   │   原始直播帧，1:1 送显，无任何 UI 叠加               │    │
│   └────────────────────────────────────────────────────┘    │
│                                                            │
│   ┌─ 水印覆盖层 (L4，透明背景，鼠标穿透) ──────────────┐    │
│   │   仅在【未激活】时可见；单个 "LiveLens" 文字水印     │    │
│   └────────────────────────────────────────────────────┘    │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**关键隔离原则**：
- 水印覆盖层是**独立 QWidget**（或等效独立绘制层），**不是**视频控件的子绘制逻辑。
- 视频显示层**不感知**水印存在。
- 覆盖层**鼠标穿透**，不得拦截预览区的任何交互。

## 2. 覆盖层规格

| 项 | 规范 |
|---|---|
| 背景 | 完全透明（`WA_TranslucentBackground`） |
| 鼠标事件 | `WA_TransparentForMouseEvents` |
| 尺寸 | 与视频显示区域**完全重合**（随预览区变化重算） |
| 层级 | 位于视频显示层**之上**（`raise_()`） |
| 绘制触发 | 独立 `QTimer`，**与视频帧率无关** |
| 定时器周期 | 见 `WATERMARK_SPEC.md` §4（默认 16ms ≈60fps 上限，可下调） |

## 3. 水印外观

| 属性 | 规范 |
|---|---|
| 文字 | `LiveLens`（固定，唯一实例） |
| 字体 | `--ll-font-lg`（16px）加粗，中文系统字体栈 |
| 文字颜色 | `rgba(233,240,255,0.30)`（半透明银白） |
| 描边 | 1px `rgba(255,255,255,0.20)` |
| 顶部高光 | 极淡的线性渐变（复用 `--ll-glass-highlight` 思路，强度减半） |
| 投影 | 可选，`rgba(0,0,0,0.30)`，偏移 (0,1) |
| 内边距 | 水平 10px，垂直 6px |
| 圆角 | `--ll-radius-sm`（6px） |

**视觉约束（任务书）**：不得使用强烈闪烁、刺眼霓虹或影响直播观看的大面积遮挡。

> 0.30 的不透明度是**起点值**，必须在 Phase 5 于真实画面上截图复核：既要"可见、能起到标识作用"，又不能干扰监看。

## 4. 运动

- 水印在**预览区内部**持续移动，碰到四边反弹（DVD 屏保行为）。
- 精确算法、边界修正、角落处理、极小尺寸安全行为 → 见 `WATERMARK_SPEC.md` §3。
- **不得**只判断中心点；必须用矩形与合法范围比较。

## 5. 显示条件（唯一条件）

| 许可状态 | 水印 |
|---|---|
| **未激活** | ✅ 显示 + 动画运行 |
| **已激活** | ❌ 隐藏 + 定时器停止 |
| **状态未确认** | ⚠️ **不得假定为已激活** —— 见 `WATERMARK_SPEC.md` §2 |

**禁止**：不得根据"是否联网""是否连接直播""试用期剩余时间"等**任何其他条件**推断激活状态。

**重要**：水印是**提示性**的，**不得**替代授权系统的安全控制。它不提供任何保护能力。

## 6. 与直播连接的关系

| 场景 | 行为 |
|---|---|
| 未连接直播 | 水印在**空白背景**（`#171B24`）上运动 |
| 已连接直播 | 水印作为**独立叠加层**在**真实画面之上**运动 |
| 断开连接 | 水印继续运动（覆盖层不随视频层销毁） |

**注意**：水印层的生命周期**独立于**视频流生命周期。不得把水印的创建/销毁绑定到视频流的开始/结束。

## 7. 禁止项

- ❌ 修改原始视频帧、解码帧、识别输入帧或帧队列。
- ❌ 把水印写入任何送入 OCR / ROI 的图像。
- ❌ 在视频帧刷新路径上做额外绘制或拷贝。
- ❌ 与水印无关的模块读取许可状态（状态应集中由许可系统提供）。
- ❌ 创建多个水印实例。
