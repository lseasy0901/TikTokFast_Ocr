# pages/toolbar.md — 顶部工具栏

> 本文件**覆盖** `MASTER.md` 中冲突的部分；未提及处遵循 MASTER。
> **完整按钮清单与信号槽映射见 `docs/ui-redesign/TOOLBAR_AUDIT.md`（Phase 2 产出）。**

---

## 1. 结构

顶部工具栏是一条 **L2 玻璃面板**，横向分为三个逻辑分区：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [① 直播控制]        [② 业务操作]              [③ 设置与辅助]              │
│  连接/断开           游戏选择/ROI/识别          设置/许可/关于              │
│  画面源             校验/纠错/自动复制           低频操作 → 溢出菜单          │
└──────────────────────────────────────────────────────────────────────────┘
```

| 分区 | 内容性质 | 可见性策略 |
|---|---|---|
| ① 直播控制 | 高频、状态强相关 | **始终可见**，主按钮用强调色 |
| ② 业务操作 | 中频、依赖连接状态 | **始终可见**（图标 + 中文标签），随连接状态启用/禁用 |
| ③ 设置与辅助 | 低频 | **图标按钮常驻**（设置/许可）；其余低频项收进溢出菜单 `⋮` |

> **硬约束（任务书目标 C）**：**不得通过删除功能来减少按钮数量。** 收纳只改变位置，不改变功能可用性。

## 2. 尺寸

| Token | 值 |
|---|---|
| 工具栏高度 | 48px |
| 分区内边距 | `--ll-space-3`（12px） |
| 分区之间 | 1px 分隔线 `--ll-glass-border` + `--ll-space-4`（16px） |
| 按钮高度 | 32px |
| 图标按钮宽 | 32px |
| 图标+文字按钮 | 自适应，图标 20px + 6px 间距 + 文字 |
| 按钮圆角 | `--ll-radius-sm`（6px） |
| 按钮间距 | `--ll-space-2`（8px） |

## 3. 按钮状态

| 状态 | 填充 | 描边 | 文字 | 过渡 |
|---|---|---|---|---|
| 默认 | 透明 | 透明 | `--ll-text-primary` | — |
| 悬停 | `rgba(255,255,255,0.06)` | `--ll-glass-border` | `--ll-text-primary` | `--ll-duration-fast` |
| 按下 | `rgba(255,255,255,0.10)` | `--ll-glass-border` | `--ll-text-primary` | `--ll-duration-fast` |
| 选中/激活 | `rgba(128,191,255,0.16)` | `--ll-accent` | `--ll-accent` | `--ll-duration-base` |
| **焦点** | 同悬停 | **2px `--ll-accent`** | `--ll-text-primary` | `--ll-duration-fast` |
| 禁用 | 透明 | 透明 | `--ll-text-secondary` @ 45% | — |
| 危险操作 | 透明 | 透明 | 红色系（沿用现有语义色） | 悬停时红色 12% 填充 |

> **焦点环来源**：Skill `--domain ux` → *Focus States (Severity: High)*："Use a visible focus ring on every interactive control"。2px 宽度来自 *Focus Appearance* 的"≥2 CSS px perimeter"。
> **禁用态**：Skill 要求对比度 4.5:1，但禁用控件按 WCAG 1.4.3 属例外。**本项目决定**：禁用态降低不透明度但**保留可读性**，并通过 `setToolTip` 说明禁用原因（避免"看不懂为什么点不了"）。

## 4. 图标

- 全部图标**同一家族**（Skill: Keep one visual family per surface）。
- 统一 20×20 px、1.5px 线宽、Outline 风格。
- 设置入口使用标准 **`gear`（齿轮）** 图标 —— 这是任务书明确要求修复的点。
- 每个纯图标按钮**必须**同时设置：
  - `setToolTip("中文说明")`
  - `setAccessibleName("中文说明")`

> **UNKNOWN（转 Phase 2）**：项目现有图标来源未审计。若现有图标无法满足"统一家族"，则**在现有资源内**重绘/替换为一致的 Outline 风格，**不得安装新依赖**。

## 5. 溢出菜单

当窗口宽度不足以容纳全部分区时：

1. 优先保留分区 ①（直播控制）与 ③ 中的设置图标；
2. 分区 ② 中的低频项折叠进 `⋮` 溢出菜单；
3. **任何情况下不得让按钮被裁剪或溢出窗口**。

## 6. 布局验证要求

必须在以下条件实测通过（Phase 4）：

| 条件 | 要求 |
|---|---|
| 窗口宽度 | 最小宽度 → 1920px |
| DPI 缩放 | 100% / 125% / 150% / 200% |
| 键盘 | Tab 可遍历全部按钮；焦点环可见；Enter/Space 可触发 |
| 溢出 | 无按钮被裁剪、无横向滚动条 |

## 7. 禁止项

- ❌ 删除任何既有功能入口。
- ❌ 改变既有信号槽连接语义、快捷键或按钮启用条件。
- ❌ 混合两种图标家族。
- ❌ 使用 Emoji 作图标。
- ❌ 用含义模糊的自绘图形代替标准图标。
