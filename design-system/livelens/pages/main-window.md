## 1. 窗口

| 项 | 规范 |
|---|---|
| 背景 | `--ll-bg-base` (`#090B10`)，不透明 |
| 窗口最小尺寸 | 待 Phase 2 读取现有 `setMinimumSize` 后确定，**不得缩小现有下限** |

| 原生材质 | 见 §4 |

## 2. 背景层次

主窗口背景由两层构成，**不使用视频帧**：

1. **L0 基底层**：`#090B10` 纯色填充。
2. **L0 氛围层（可选）**：极低对比度的径向渐变（中心 `#10141C` → 边缘 `#090B10`），用于制造"空间深度"。

> **来源**：Skill `Liquid Glass` 关键词含 *depth* / *multi-layer*；`--domain style` 提到 *Z-depth* 分层。
> **约束**：氛围层必须是**静态**的，不得动画；不得在视频帧路径上绘制。

## 3. 区域划分

| 区域 | 材质层 | 说明 |
|---|---|---|
| 顶部工具栏 | L2 玻璃面板 | 见 `pages/toolbar.md` |
| 直播预览区 | L1 内容面板 | 外框 `#171B24`；内部由视频控件自行绘制 |
| 侧边面板（如有） | L2 玻璃面板 | 与工具栏同材质 |
| 状态栏 | L1 内容面板 | 底部，含帧率/连接状态 |

## 4. Windows 原生材质（待实测）

**UNKNOWN — Phase 6 决策项**，不得提前假定可用：

- `DwmSetWindowAttribute` + `DWMWA_SYSTEMBACKDROP_TYPE`（Mica / Acrylic）需要 Windows 11 22H2+；
- Qt 6.11 对 DWM backdrop 无官方封装，需 `ctypes` 调用；
- 与无边框窗口 / 自定义标题栏组合时的行为未知。

**处置**：Phase 6 先写**独立最小原型**验证（单独脚本，不进主程序），确认可行且不引起重绘/闪烁后再决定是否纳入。**默认方案是 QPainter 自绘玻璃，不依赖原生材质。**

## 5. 禁止项

- ❌ 不得为视觉效果修改窗口标志位（flags）导致任务栏行为、最大化/还原、DPI 缩放改变。
- ❌ 不得在 `paintEvent` 中对视频帧做任何处理。
- ❌ 不得引入未经批准的第三方 UI 库。
